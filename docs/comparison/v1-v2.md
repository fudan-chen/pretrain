# v1 与 v2 对比指南

## 对比对象

- `main@9c61dc2`：公开生态证据采集。
- `marin-deep-track@65bb272`：第一版深度追踪。
- `codex/cloud-marin-tracker@af5c5f9`：最初云端工作流。
- `codex/marin-learning-v2`：本次非破坏性整合与重构。

原远端分支均保持不动。本文件解释差异，不要求删除旧内容。

## 旧版应保留的价值

- 视觉层级、色彩与 KPI→下钻的产品意识。
- 对 Scaling Ladder、Hero、Router、datamix 和系统信号的广泛覆盖。
- 官方图与公开证据的集中整理。
- 早期自动化探索形成的运维经验。

## 旧版不再作为当前事实的内容

- 终点 fit 生成的全程预测曲线。
- Train CE 与 Paloma prediction 的同轴比较。
- “约 9% 已越过 25% 峰值区”。
- WSD/cosine、TPU v5p、active 792 cards。
- Router overflow 固定约 0.1–0.2%。
- phase 2 必然转向更高质量课程。
- 吞吐稳定即可证明 all-to-all 无瓶颈。

这些内容继续留在旧分支，作为“证据纪律为什么重要”的案例。

## 不应夸大的 v2 范围

v2 Phase 1 修复的是 matched-progress 主线与证据/展示契约，不是一次性完成旧报告提出的全部研究问题。它尚未交付 Paloma 16 域归因、完整 Router heatmap、datamix phase delta、系统通信归因、事故因果链或统计预测区间。旧版覆盖面更广但结论纪律不足；v2 当前结论更窄，但每一步更容易复查与反证。
