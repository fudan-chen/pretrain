04 / METRIC CONTRACTS

其余信号：能观察什么，不能证明什么

grad/norm/total

用于观察尺度、尖峰和阶段形态。约 25% 只是经验参考，不是报警阈值。

throughput/mfu

适合看同一 run 内变化；跨硬件、跨 FLOPs 定义的 MFU 不宜直接排名。

moe/drop_fraction

反映 token drop；稳定吞吐不能单独证明 all-to-all 不构成瓶颈。

train/router/*

当前采集是 aggregate + edge layers，并非完整 48 层热力图。
